A pipeline is right when you can run it again, on any day, and get the right answer.

Floor 1: Run it twice

Your task: Build trips_clean from day 1 of raw_trips. Run the same pipeline twice with nothing new. Both runs must produce the same 2,400 trips and $68,624.30 in revenue.

Trip key: trip_id names the trip; row_id and loaded_at name the load. A re-send or correction keeps the same trip_id.

Repeatable table tip: CREATE OR REPLACE TABLE trips_clean AS … can replace an earlier result each time. Write the SQL in Pipeline; Scratch queries are for exploring and never run in a check.

What counts as a pass

Keep exactly the 14 raw columns, in any order, with one row per trip_id. Keep each output row as an unchanged, complete row from raw_trips. Add no output columns and leave raw_trips unchanged. Helper tables are allowed. Rows and values are compared, independently of their order; correct counts alone do not pass. Money compares to cents. Keys, timestamps and every other value compare exactly, with NULLs treated as equal.

On days 1 and 2, either unchanged copy of an identical trip is accepted; only row_id and loaded_at are ignored when comparing trip content. The full output row must still come from one real raw row. After day 3 arrives, the latest whole row must match, including its load metadata.

An append can double the output. A plain CREATE TABLE can fail because yesterday’s table exists. Predict the second run before pressing it.

The full check sequence

day1-first → day1-repeat

Each floor starts fresh with day 1. Floor 1 runs every condition above, including earlier floors’ conditions. Check floor uses isolated copies and never changes your workspace. Scratch tables and queries cannot help it pass. Every run must pass; the first failure names the condition, without giving the fix.

All 14 input columns

trip_id, row_id, vendor_id, pickup_at, dropoff_at, passenger_count, trip_distance, pu_location_id, do_location_id, payment_type, fare_amount, tip_amount, total_amount, loaded_at

Counts to reconcile

  • Day 1: 2,400 raw rows; 2,400 output rows and trips; $68,624.30 output revenue.
