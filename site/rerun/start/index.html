About The Rerun

The game

Write one pipeline script. It must give the right answer every time it runs, on any day.

The game has three floors.

The data

These are real New York City TLC yellow taxi trips from January 2024. The game uses 7,171 trips, delivered as three daily loads. Day 1 has 2,400 trips. loaded_at names the load, not the pickup date.

The course added re-sends and corrections to teach pipelines, and these are not TLC errors.

Read the TLC trip record data page and the yellow taxi data dictionary (PDF).

Column meanings

trip_idThis game's stable id for a trip.
row_idThis game's id for a row in a load.
vendor_idA code for the provider that supplied the record.
pickup_atThe date and time when the meter was engaged.
dropoff_atThe date and time when the meter was disengaged.
passenger_countThe number of passengers in the vehicle.
trip_distanceThe trip distance in miles reported by the meter.
pu_location_idThe TLC Taxi Zone where the meter was engaged.
do_location_idThe TLC Taxi Zone where the meter was disengaged.
payment_typeA numeric code for how the passenger paid.
fare_amountThe time-and-distance fare calculated by the meter.
tip_amountThe tip amount. Card tips are included; cash tips are not.
total_amountThe total amount charged to passengers. Cash tips are not included.
loaded_atThis game's time when the load arrived.

What each floor teaches

Floor 1: Run it twice

Task: Run the same pipeline twice.

Why: An append can double the output.

  • Textbook M6I4: Run It Again, the double-load
  • Textbook M6I4: Run It Again, start from a known state
  • In-person section: Week 9 Tuesday Class

Floor 2: A new day

Task: Add a day and keep one row per trip.

Why: A new delivery is not always a new trip.

  • Textbook M6I4: Run It Again, loads that only add
  • Textbook M3I3: Pattern 1, rank rows within a group
  • In-person section: Week 9 Tuesday Class

Floor 3: Late corrections and rebuild

Task: Keep the latest trip version and rebuild from raw data.

Why: Raw data can rebuild the result.

  • Textbook M6I4: Run It Again, the raw copy pays off
  • Textbook M6I2: Copy faithfully, change nothing
  • Textbook M3I3: Pattern 1, rank rows within a group
  • In-person section: Week 9 Thursday Class

The tutor

The tutor sees the game’s guide, your pipeline, and recent query results. It uses its own copy of the raw data.

You get 40 questions a day and four questions a minute. A failed answer does not use a question.

Privacy

Your tutor messages go to Anthropic's API to get an answer. Your name and NetID are not sent.

Chats stay on the course server under a random ID. They are deleted after final grades. Forget me deletes your chat.

Do not type personal information.
