Four range rules

Write one rule per problem. Count each rule on its own before you combine them.

Lv 2 · How the check works

The rules, in this order:

  1. negative_fare: fare_amount < 0
  2. time_travel: dropoff_at < pickup_at
  3. outside_january: the pick-up is before 1 January 2024, or on or after 1 February 2024
  4. zero_distance_high_fare: trip_distance = 0 and fare_amount >= 50

These four columns have no NULLs. zone_flag is not a quarantine reason.

Lv 3 · The real SQL

SELECT
  count(*) FILTER (WHERE fare_amount < 0) AS negative_fare,
  count(*) FILTER (WHERE dropoff_at < pickup_at) AS time_travel,
  count(*) FILTER (WHERE pickup_at < TIMESTAMP '2024-01-01'
                      OR pickup_at >= TIMESTAMP '2024-02-01') AS outside_january,
  count(*) FILTER (WHERE trip_distance = 0
                     AND fare_amount >= 50) AS zero_distance_high_fare
FROM trips;

The first rule wins

One row fails two rules. It appears once in your answer, with the first reason it fails.

Lv 2 · How the check works

If you stack the four rules with UNION ALL and do not exclude earlier rules, that row appears twice: 217 rows instead of 216. A CASE tests the rules in order and stops at the first match.

Watch the January bound: pickup_at <= '2024-01-31' loses every trip on 31 January after midnight.

Lv 3 · The real SQL

CASE WHEN fare_amount < 0 THEN 'negative_fare'
     WHEN dropoff_at < pickup_at THEN 'time_travel'
     WHEN /* outside January */ THEN 'outside_january'
     WHEN /* zero miles, fare of 50 or more */ THEN 'zero_distance_high_fare'
END AS reason  -- NULL: the row passes every rule

Quarantine, do not delete
